How it works (offline)
  1. Host taps “Create room” and chooses a password.
  2. Host taps “Generate Join Code” and shows the code to a friend.
  3. Friend pastes the Join Code, then taps “Generate Answer Code”.
  4. Host pastes that Answer Code. The chat opens.
This uses local WebRTC connections with no STUN/TURN servers. Works on the same Wi‑Fi/hotspot without internet. The host relays messages between people in the room.
